# Simulador de planificación de CPU

Simuladores interactivos en HTML (sin dependencias):

- `index.html`: FCFS, SJF, SRTF y Round Robin con Gantt, paso a paso y métricas.
- `so-reales.html`: planificadores de Windows, Linux (CFS) y Solaris (clase TS).

Abre `index.html` en el navegador o publícalo con GitHub Pages (workflow incluido).
